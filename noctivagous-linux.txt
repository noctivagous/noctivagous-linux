noctivagous linux

- AI models, modalities, frameworks, providers, mcp servers,
sandboxes, etc. available at system level and to apps
in native framework.
	- tools for AI researchers, native
	- app/development framework has graphs, algorithms built in
	of all kinds.
		- much of the noctivagous linux desktop environment
		will be driven by live graphs. and the File Navigator
		will be rendering from a graph.
	- automatically fetches and sorts models in manager 
	from existing providers, with logos, modalities.
- built on top of debian (likely)
- MetaFont utilized (likely)

Commonly Needed Managers (GUI)
	separate apps that manage versions, packages,
	dependences.
	Python
	Node
	PHP

UI
- custom layout engine, noct-layout-engine.
	- base layer: noct-layout-engine
	- grids as first-class framework inclusion, behind
	all GUI.
		print: module grid, compound grid, column grid
	- designed from the ground up for multiple targets
	per app ("responsive design") breakpoints.
- SVG-based UI images with embedded bitmap images
when necessary.

File Navigator
- Git in the File Navigator UI.

Graphics
- Pro App GUI toolkit, has sliders, panels, etc. of various
kinds so that software developers can make pro apps.
- SVG-N - Noctivagous SVG, based off .fmarker files from
Floating Marker that descend to base SVG when unsupported, 
are viewable with hidden tags.  Will support mesh gradients, alternative
shading methods.
- Tessellation utilities native to the app framework.
- 3D parametric libraries like iGeo native to the app framework.


App Framework
- dedicated to bases like paramorphic components
that can make apps from morphic elements.   
Paramorphic Components Runtime bridges to system framework.
  - native support for XULRunner updated and extended
  too.
- no app imports that look out of place.

- built-in support for AI - mcp servers, sandboxing
in settings.
