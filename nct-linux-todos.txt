nct modules.

important note is that modules can be marked as
available to shell scripts, so that shell scripts come
with a lot of functionality.  

it looks as though as we build this, there is blending
of the conventional services and app kit.  in fact it
may be an exposure that this should be this way
since when people use the command line they
often have to install functionality that is already
inside the local dev app kit but requires compilation
for those apps to use it.  e.g. shell scripts can't
make use of any .framework files in Mac OS.
Furthermore, an AI agent built into the system
will have access to these utilities and won't
have to install equivalent functionality from
packages when carrying out tasks.
e.g. Any app can get access to map and geo services.

-- nct-api-gateway - the app in the environment lets you
set up API information so that it can be utilized by apps
as part of the NCT app kit (or other apps that use the
gateway service).  allows for setting keys and permissions
so that an app has to be given a key before it can use an
API.  Comes with presets for common service types.
   -- familiar with protocols, authentication.
   -- Allows for making use of APIs in a central location.
   shell scripts can make use of them, NCT apps can,
   any app given access to the nct-api-gateway.

do file conversion and export.  utilized by the contextual-menu.
