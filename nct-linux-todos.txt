-- nct-api-gateway - the app in the environment lets you
set up API information so that it can be utilized by apps
as part of the NCT app kit (or other apps that use the
gateway service).  allows for setting keys and permissions
so that an app has to be given a key before it can use an
API.
   -- familiar with protocols, authentication.
   -- Allows for making use of APIs in a central location.
   shell scripts can make use of them, NCT apps can,
   any app given access to the nct-api-gateway.
