# Keyboard Only — Input Set

Status: PLACEHOLDER — definition reserved, design pass owed.

What it declares: a keyboard is present and NO pointing
device may be assumed. Nothing may require a pointer.
This set is close to native for this system: the desktop is
built on key-clicks, so steering is by Tab and labels and
activation is by key — the keyboard-steered form of the
Bimodal modality. This is also an accessibility
configuration — nct-accessibility-manager carries a slice.

Stored as: modes.input-set = keyboard-only
