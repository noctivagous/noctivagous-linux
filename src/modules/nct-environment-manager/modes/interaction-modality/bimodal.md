# Bimodal — Interaction Modality (strict)

Status: PLACEHOLDER — definition reserved, design pass owed.

What it divides: steering and activation are kept in
separate device locations, as Bimodal Control Theory
states it — the mouse steers only; the keyboard activates
only (key-clicks, with text mode for typing). Unlike the
default, the mouse buttons do NOT activate. The pure form,
a deliberate opt-in; under Input Set Keyboard Only it takes
its keyboard-steered form (Tab and labels steer the
target, keys activate).
