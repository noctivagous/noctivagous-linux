# Conventional — Interaction Modality

Status: PLACEHOLDER — definition reserved, design pass owed.

What it divides: nothing — the ordinary desktop arrangement
every other system ships. The mouse steers AND activates;
the keyboard types and takes shortcuts. Bimodal control is
off. Kept as a value for guests and familiarity, for any
app that misbehaves under key-clicks, and because it is the
only modality available under Input Set Mouse Only.

Stored as: modes.interaction-modality = conventional
