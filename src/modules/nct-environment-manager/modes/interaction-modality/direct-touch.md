# Direct Touch — Interaction Modality

Status: PLACEHOLDER — definition reserved, design pass owed.

What it divides: nothing — the finger steers and activates
in one place. This is the condensed single-location
arrangement bimodal theory argues against for a mouse, and
the natural one for touch. The default modality under
Input Set Touchscreen. (The bimodal arrangement for a
tablet — touch steers, a designated on-screen click button
activates — is in refs/bimodal and is NOT ruled out as a
future value.)
