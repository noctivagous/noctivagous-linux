# ext-core-utils/ — NCT-LIB-EXT-CORE-UTILS

The leaf-utility tier of the external core dependencies (parsers,
loaders — e.g. the XML library under the compositor). Nothing above the
core names these directly; they are recorded here so every external
library the foundation relies on has a named home and a pin.
Foundation state: empty by design; first entry lands with the first
leaf dependency the core actually takes.
