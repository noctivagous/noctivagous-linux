# godot/shell — the shell (foundation form)

A Godot project: a bar with a clock and one button per launch-list
entry, each button running `nct-launch <id>`. It holds no program paths.
`-- --self-test` prints the parsed list and exits (tier-0 check).
The full shell furniture (launch bars, dock, sysbar, widgets) is designed
in demo-de and lands here piece by piece; this is its landing slot.
