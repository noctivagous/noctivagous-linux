# godot/kit — the NCT Godot Kit

Marker: NCT-WL-KIT. The toolkit contract NCT Godot apps satisfy:
controls, theme-from-tokens, device classes. Foundation state:
tokens.json only — the style-token map (panel/glass/recessed) that the
kit will turn into Godot Theme resources, the same map bridged apps
receive in StyleSetChanged (see ../ext-fwks and demo-de/EXT-FWKS.md).
