# agent-build-log/ — what the agent built, section by section

One file per work section, written when the section finishes (or when
it stops, with the reason). Each file states: what was asked, what was
done, the decisions taken and who took them, the evidence for every
claim of "works", and what was left open. These files are the record
the owner (and any later agent, including Muse Code on the rig)
reads instead of reconstructing history from commits.

Convention: files are numbered in the order the work happened;
a Stage 2 slice gets the next number when it completes. Claims in
these files follow the house rule — what was done, what it shows,
what it does not show, and what nobody has checked yet.
