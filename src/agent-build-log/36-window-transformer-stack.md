# 36 — WindowTransformer: shade into the stack on stock labwc (route 1c, first half)

2026-11-27. Branch feat/greeter-look-registry, on 19f01ec.

## The requirement and the decision

Shade on foreign windows is a hard requirement (owner,
2026-11-27). It fires the compositor deferral condition —
stock labwc cannot be the final compositor as-is. The route
research, checked against primary sources the same morning:
Wayfire has no shade anywhere in its wm-actions; Waybox has
Shade/Unshade since 0.2.0 but is unpackaged in Debian and
wants wlroots 0.17; the "Waybox PR #142 (Nov 2026)" cited in
conversation does not exist (that repo's PRs top out at #47);
labwc upstream has no shade issue or PR at all.

Owner's decision (1c): build BOTH, transformer first —

1. a shell-side WindowTransformer on stock labwc: a foreign
   window collapses into a WindowTransformer Region stack,
   the Flat Space semantics (demo-de windows.js/store.js:
   `shaded` and `stacked` are separate record states; a
   transformed window renders nowhere, its record keeps its
   geometry; a stack item restores the window, and its ×
   closes it without leaving the stack). Faked honestly: the
   window vanishes into the stack rather than collapsing in
   place — the one divergence from the demo, stated up front.
2. the labwc in-place Shade/Unshade patch afterwards
   (queued; 0.8.3 source staged, no patch code yet).

This log is (1).

## What was built

**nct-wl-bridge** (`src/services/bridge/nct-wl-bridge.c`) —
the house bridge pattern (marker NCT-WL-BRIDGE), the tree's
one compiled C artifact. It holds labwc's
wlr-foreign-toplevel-management binding on one side (the
protocol XML is vendored beside it; the generated code is a
build-time product) and a one-line TCP protocol on
127.0.0.1:7718 on the other:

    PING            -> PONG
    LIST            -> TOP <id> <app_id> <act> <min> <stacked> <title> ... END
    SHADE_ACTIVE    -> OK <id> | FAIL <why>
    RESTORE <id>    -> OK | FAIL
    CLOSE <id>      -> OK | FAIL

A toplevel reads "stacked" iff this bridge minimized it via
SHADE_ACTIVE and it has not been unminimized since; the
compositor state feed heals the flag. Client modes
(`shade-active | list | restore <id> | close <id>`) serve
the keybind shim and the proof scripts. A fixture backend
(NCT_WL_FIXTURE, a stateful TSV table) backs the local
tests. labwc 0.8.3's own source confirmed it honors foreign
minimize/activate/close requests (foreign.c), so the whole
transformer is compositor requests, not compositor surgery.

The bridge was first attempted in Python (pywayland); that
route was dropped for cause, recorded in the C file's
header: Debian's python3-pywayland ships no wlr protocol
modules and its import needs a cffi package it does not
declare, and once bindings were generated by hand its
dispatch loop segfaulted under a trivial probe. The C
bridge links only libwayland-client and compiled
warning-free under -Wall.

**The stack region** (`src/godot/shell/stack_host.gd`) — a
Control sibling of BarHost in the shell. It polls the bridge
LIST once a second (the process watcher's cadence) and
renders a panel at the top-right under the bar, in the bar's
styling: one row per stacked window, title button + ×.
Row click sends RESTORE, × sends CLOSE. A `--stack-test`
mode in main.gd proves it against the fixture backend.

**Session wiring** — labwc's rc.xml gains exactly one
keybind, Super+S → `nct-shade-active` (a shim in
core/session that execs the bridge client); the header
comment records that shade is the one policy exception
whose key lives in the compositor file while the policy
lives in the shell. nct-session-apps starts the bridge
daemon inside the live compositor before any app launches
(guarded on WAYLAND_DISPLAY + the binary existing).
build-deb.sh compiles the bridge into the foundation deb
(build machines now need libwayland-dev + libwayland-bin).
Known wart: the foundation deb is Architecture: all but now
contains one amd64 ELF — it was already de-facto amd64.

**The shell must never shade itself** (found in the guest,
below): the shell is itself a foreign toplevel, and before
this was handled, Super+S with the shell focused would have
minimized the desktop into its own stack. NCT_WL_EXCLUDE_
APP_IDS entries are a bare app_id, or app_id:titleprefix.
The session sets `Godot_Engine:NCT Shell` — every Godot
window reports app_id Godot_Engine, the shell alone is
titled "NCT Shell...", so NCT Hello and every other Godot
app stay shadeable.

## Two build-time facts this slice cost

- A GDScript parse error fails silently headless and the
  run HANGS (it wedged the chain twice before the cause was
  isolated). The two errors: a method named `is_connected()`
  overrides Object.is_connected (signal API) and is a parse
  error; and `:=` cannot infer from an untyped Array
  returned through a Control-typed reference. Also:
  adding an ext_resource to a .tscn requires bumping
  load_steps to match.
- /tmp does not survive a runtime restart of this sandbox;
  test binaries staged there vanish mid-proof. Stage under
  ~/workspace.

## Notes / limits

- In the guest, restore and close were issued through the
  bridge client — the identical protocol commands the
  stack rows send; the row-click path itself is proven
  headlessly by the chain's stack test. The split exists
  because of a real defect this proof found: **the stack
  rows are not in the keyboard focus chain.** Tab cycles
  the four bar buttons only (verified across eight Tabs
  and three screenshots). In a key-click-first environment
  the stack must be keyboard-reachable; that is a
  follow-up fix, not a footnote — the transformer is
  mouse-complete and keyboard-partial today.
- The shell reaches the compositor as an XWayland window
  (render ladder's X11 rung on this guest), app_id
  Godot_Engine. On a native-Wayland rung its app_id may
  differ; the exclusion's title prefix is the stable half.
- Under sway the same bridge lists windows but sway
  declines to minimize a tiled window (stacked flag set,
  minimized stays 0) — a sway trait; labwc is the target
  compositor and honors the request.
- Route 1c's second half — the labwc in-place shade patch —
  remains queued. The transformer does not depend on it.
- Push awaits the owner's word, as always.
